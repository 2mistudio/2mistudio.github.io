關於 CSS

CSS 全名為 Cascading Style Sheets，中文常譯為「層疊樣式表」或「階層式樣式表」。是一種用來描述 HTML 或 XML 等結構化文件，並將其視覺呈現的樣式表語言。

在網頁剛被發明時，網頁的目的只是為了讓科學家方便分享學術論文。當時的 HTML 只是純粹用來表現「這是標題」、「這是段落」、「這是項目清單」⋯ 等結構化內容以方便閱讀，沒有任何可以改變顏色、字型或精準排版的標籤。網頁傳送到不同的電腦上，會直接套用該台電腦瀏覽器的預設外觀（字體、顏色、排版設定 ⋯ 等）。

對網頁設計樣式的需求

隨著網頁走向大眾，大家開始希望網頁可以有如書本雜誌一般漂亮的字型、繽紛的色彩和精緻的排版。為了回應市場需求，HTML 的規格開始妥協，陸續加入了可以控制外觀的「樣式標籤」與「屬性」：

  • 外觀標籤：例如 <font>（指定字型與顏色）、<center>（強行置中）、<b>（粗體）、<i>（斜體）。
  • 外觀屬性：在原本的結構標籤上加上控制外觀的參數，例如 <body bgcolor="yellow">（把整個網頁背景變黃色）

樣式過多造成的混亂

HTML 設計的初衷在於呈現內容的結構，但加入樣式設定之後，這些設計樣式不但在網頁中爆發性的成長，多到影響到結構內容的檢視，各家 瀏覽器為了搶市佔率，甚至推出專屬的樣式標籤與功能。這個情況導致網頁程式碼大量出現「肥胖症」、「結構污染」與「維護地獄」等問題。當時的網站甚至必須請工程師寫出「IE 微軟專用版」與「Netscape 網景專用版」兩個完全獨立的網頁檔案，才能讓所有人都看得到同樣漂亮的網頁。

外觀樣式與內容結構分離

經歷了上述的失控與混亂之後，網頁開發者開始正視到問題的嚴重性，網際網路標準組織（W3C）於是聯手 CSS 的發明人 Håkon Wium Lie (哈肯·維姆·萊) ，於 1996 年制定出第一版 CSS 樣式標準，確立了「HTML 只管內容、CSS 只管外觀」的規則。
