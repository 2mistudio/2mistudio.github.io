Day 7: CSS Grid 網格排版系統

CSS Grid Layout

一、學習目標

完成本日課程後，你將能夠：

  • 理解 Grid 與 Flexbox 的差異與適用時機
  • 使用 grid-template-columns 與 grid-template-rows 定義網格
  • 掌握 fr 單位與 repeat() 函式
  • 使用 grid-column、grid-row 讓項目跨欄跨列
  • 使用 grid-template-areas 建立具名版面

二、Grid 簡介

CSS Grid（網格佈局）是專為二維佈局（同時控制橫向的行與直向的列）而設計的系統。

Grid 與 Flexbox 的選擇：

Flexbox Grid
維度 一維（一行或一列） 二維（行與列同時控制）
設計思維 由內容決定佈局 由網格決定佈局
適用場景 導覽列、按鈕群組、元件內部排列 整頁版面、卡片網格、複雜排版

Grid 與 Flexbox 都是新一代的網頁排版系統。兩者的運作邏輯不同，但各有強項。視排版情境的不同，兩者可以搭配使用。並沒有說哪個一定比較好，或是非怎麼安排才是對的。不過網路上有此一說：Grid 處理整體版面，Flexbox 處理內部元件。

基本概念

兩個核心角色（與 Flexbox 相同）：

  • Grid Container（容器） - 設定 display: grid 的父元素
  • Grid Items（項目） - 容器內的直接子元素

名詞說明：

  • Grid Line（網格線） - 分隔行與列的線，編號從 1 開始
  • Grid Track（軌道） - 兩條相鄰網格線之間的空間（一欄或一列）
  • Grid Cell（儲存格） - 行與列交會的最小單位
  • Grid Area（網格區域） - 由多個儲存格組成的矩形區域

三、Grid Container 屬性

1. display

啟用 Grid 佈局。


display: grid;         /* 區塊級 Grid 容器 */
display: inline-grid;  /* 行內 Grid 容器 */

2. grid-template-columns / grid-template-rows

定義直欄（column）與橫列（row）的數量與尺寸。


grid-template-columns: 200px 200px 200px;  /* 三欄，各 200px */
grid-template-columns: 1fr 2fr 1fr;        /* 三欄，比例 1:2:1 */
grid-template-columns: 200px 1fr;          /* 固定 + 彈性 */
grid-template-rows: 100px auto 100px;      /* 三列 */

3. fr 單位

fr（fraction）代表 剩餘空間的比例，是 Grid 專用的特殊單位。
可以試著用中文的「份」去理解它，例如（一塊麵包切幾份）。


grid-template-columns: 1fr 1fr 1fr;  /* 三等分 */
grid-template-columns: 1fr 2fr;      /* 第二欄是第一欄的兩倍寬 */
grid-template-columns: 250px 1fr;    /* 側邊欄固定，內容區佔滿剩餘空間 */

4. repeat() 函式

將相同的尺寸用repeat() 取代，可避免重複書寫，讓語法更精簡。


grid-template-columns: repeat(3, 1fr);       /* 等同 1fr 1fr 1fr */
grid-template-columns: repeat(4, 100px);     /* 四欄，各 100px */
grid-template-columns: 200px repeat(2, 1fr); /* 可與其他值混用 */

5. minmax() 函式

設定 Grid 軌道的最小與最大尺寸。


grid-template-columns: repeat(3, minmax(200px, 1fr));
/* 每欄最小 200px，最大平分剩餘空間 */

6. gap

設定 Grid 軌道之間的間距（用法與 Flexbox 相同）。
小常識：gap 語法最早出現在 grid 排版中，因為太好用了，所以後來才在 flexbox 排版中也導入 gap 語法。


gap: 20px;        /* 行列間距都是 20px */
gap: 20px 10px;   /* 列間距 20px，欄間距 10px */
row-gap: 20px;
column-gap: 10px;

7. 自動換欄：auto-fit

讓瀏覽器根據容器寬度，自動決定能放幾欄，非常適合用在響應式的版面。
小常識：gap 語法最早出現在 grid 排版中，因為太好用了，所以後來才在 flexbox 排版中也導入 gap 語法。


grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));

意思是： 每欄至少 200px，空間夠就多放一欄，不夠就自動換行。不需要 Media Query 就能做出基本的響應式效果。

8. 項目對齊

在 儲存格內對齊項目：
小常識：gap 語法最早出現在 grid 排版中，因為太好用了，所以後來才在 flexbox 排版中也導入 gap 語法。


justify-items: stretch;  /* 水平：拉伸填滿（預設） */
justify-items: start;    /* 靠左 */
justify-items: center;   /* 置中 */
justify-items: end;      /* 靠右 */

align-items: stretch;    /* 垂直：拉伸填滿（預設） */
align-items: start;      /* 靠上 */
align-items: center;     /* 置中 */
align-items: end;        /* 靠下 */

place-items: center;     /* 簡寫：align-items + justify-items */

整個網格在容器內的對齊（網格比容器小時才有效）：


justify-content: center;  /* 水平置中整個網格 */
align-content: center;    /* 垂直置中整個網格 */

9. grid-auto-rows

當項目數量超過已定義的列數，Grid 會自動產生新列。用這個屬性控制自動產生列的高度。


grid-auto-rows: 100px;
grid-auto-rows: minmax(100px, auto);  /* 最小 100px，內容多就長高 */

四、Grid Items 屬性

1. grid-column / grid-row

指定項目從哪條網格線開始、到哪條結束。


grid-column: 1 / 3;     /* 從第 1 條線到第 3 條線（橫跨 2 欄） */
grid-column: 2 / 4;     /* 從第 2 條線到第 4 條線 */
grid-row: 1 / 3;        /* 橫跨 2 列 */

使用 span 指定跨越數量：


grid-column: 1 / 3;     /* 從第 1 條線到第 3 條線（橫跨 2 欄） */
grid-column: 2 / 4;     /* 從第 2 條線到第 4 條線 */
grid-row: 1 / 3;        /* 橫跨 2 列 */

使用 -1 代表最後一條線：


grid-column: span 2;      /* 橫跨 2 欄 */
grid-row: span 3;         /* 橫跨 3 列 */
grid-column: 1 / span 2;  /* 從第 1 條線開始，橫跨 2 欄 */

2. justify-self / align-self

這邊的用法跟 flex 很像，單獨控制某個項目在儲存格內的對齊（覆蓋容器的 justify-items / align-items）。


justify-self: center;
align-self: end;
place-self: center;  /* 簡寫 */

3. grid-template-areas 與 grid-area

用類似「畫圖」的方式命名區域，再把項目放進去，是最直觀的版面寫法。

步驟 1：在容器中定義區域


grid-template-areas:
  "header header"
  "sidebar main"
  "footer footer";

步驟 2：在項目中指定區域名稱


.header { grid-area: header; }

規則：

  • 每個字串代表一列
  • 同名稱的相鄰儲存格會合併為一個區域，且必須是矩形
  • 用 . 表示空白儲存格

五、Grid 程式碼範例

1. 基本網格


/* 三欄等寬 */
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}

/* 固定側邊欄 + 彈性內容 */
.layout {
  display: grid;
  grid-template-columns: 250px 1fr;
  gap: 20px;
}

2. 跨欄跨列


.grid {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  grid-auto-rows: 100px;
  gap: 10px;
}

.wide {
  grid-column: span 2;  /* 橫跨 2 欄 */
}

.tall {
  grid-row: span 2;     /* 橫跨 2 列 */
}

.full {
  grid-column: 1 / -1;  /* 橫跨整列 */
}

3. 自動換欄的卡片網格


.card-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
  gap: 20px;
}

4. 經典網頁版面

HTML：


<div class="page">
    <header> Header </header>
    <aside> Sidebar </aside>
    <main> Main </main>
    <footer> Footer </footer>
</div>

CSS：


.page {
  display: grid;
  grid-template-columns: 250px 1fr;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header  header"
    "sidebar main"
    "footer  footer";
  min-height: 100vh;
  gap: 20px;
}

header { grid-area: header; }
aside  { grid-area: sidebar; }
main   { grid-area: main; }
footer { grid-area: footer; }

置中


.center {
  display: grid;
  place-items: center;
  height: 100vh;
}

六、常見錯誤與注意事項

錯誤 1: 忘記設定 display: grid

問題示範：


/* ❌ 沒有 display: grid，欄位設定無效 */
.container {
  grid-template-columns: repeat(3, 1fr);
}

正確做法：


/* ✅ 先啟用 Grid */
.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
}

錯誤 2: 混淆「網格線」與「欄位」編號

grid-column: 1 / 3 的 3 是第 3 條線，不是第 3 欄。這個設定橫跨的是 2 欄，不是 3 欄。
三欄網格有 4 條網格線（1、2、3、4）。


/* 橫跨全部三欄 */
grid-column: 1 / 4;   /* ✅ 從第 1 條線到第 4 條線 */
grid-column: 1 / -1;  /* ✅ 更方便，不用數線 */
}

錯誤 3: grid-template-areas 區域不是矩形

問題示範：


/* ❌ L 形區域無效，整個設定會被忽略 */
grid-template-areas:
  "a a"
  "a b";

正確做法：


/* ✅ 區域必須是矩形 */
grid-template-areas:
  "a a"
  "b b";

錯誤 4: 每列的欄數不一致

問題示範：


/* ❌ 第一列 3 欄，第二列 2 欄 */
grid-template-areas:
  "header header header"
  "sidebar main";

正確做法：


/* ✅ 每列的欄數必須相同 */
grid-template-areas:
  "header  header header"
  "sidebar main   main";

錯誤 5: 對孫層元素設定 Grid 屬性

Grid 屬性只對直接子元素有效，與 Flexbox 相同。


<div class="grid">
  <div class="item">
    <p>這裡的 p 不是 Grid Item</p>
  </div>
</div>

七、重點整理

1. Grid 與 Flexbox 不是二選一

  • 整體版面用 Grid
  • 元件內部排列用 Flexbox

2. fr 與 % 的差異

  • fr 會自動扣除 gap
  • 使用 % 加上 gap 容易超出容器寬度

3. 隱式網格

  • 項目數量超過定義的列數時，Grid 會自動新增列
  • 使用 grid-auto-rows 控制其高度

4. 項目的順序

  • 沒有指定位置的項目，會依照 HTML 順序自動填入
  • 指定位置的項目會先被放置

5. 瀏覽器開發者工具

  • Chrome / Firefox 的開發者工具可以顯示 Grid 網格線
  • 在 Elements 面板點擊元素旁的 grid 標籤即可開啟

6. 瀏覽器支援

  • 現代瀏覽器全面支援 CSS Grid 語法（全球瀏覽器支援超過97%）
  • IE 10-11 只有部分支援，有 IE 瀏覽器相容需求的話不建議使用（支援性有 bug，但目前 IE 已幾乎完全退役）
  • CSS Grid 目前已成為 實際使用基準 Baseline
