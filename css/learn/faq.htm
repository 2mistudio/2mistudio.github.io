FAQ 常見問題

Frequently Asked Questions

Q: 我沒有設計或程式背景，能學 CSS 嗎？

A: 完全可以！CSS 不是程式語言，沒有複雜的邏輯運算，主要是「描述外觀」。只要懂基本的 HTML 標籤，就能開始學習。

Q: 我英文不好，能學 CSS 嗎？

A: 當然可以！CSS 的屬性名稱大多是常見的英文單字（color、width、margin、border 等），多寫幾次就會熟悉。遇到不確定的單字，可以用翻譯工具輔助。

Q: 每天 1 ～ 2 小時夠嗎？

A: 夠的。學習的重點是「持續」而非「速成」。如果時間充裕，可以多花時間動手練習，把每天的範例自己重新打一遍。

Q: 我寫的 CSS 沒有任何效果，怎麼辦？

A: 先別緊張，CSS 出錯時通常不會顯示錯誤訊息，而是「默默失效」。可以依序檢查：

  • CSS 檔案是否有正確引入（路徑是否正確）
  • 選擇器是否正確（Class 要加 .，ID 要加 #）
  • 屬性名稱、數值是否拼錯，結尾是否漏了分號 ; 或大括號 }
  • 是否被其他更高優先級的規則覆蓋
  • 按 F12 開啟開發者工具，檢查該元素實際套用了哪些樣式（被劃掉的就是被覆蓋或無效的）

Q: 為什麼我改了 CSS，網頁看起來還是一樣？

A: 通常是瀏覽器快取的關係。可以試試：

  • 強制重新整理（Windows：Ctrl + F5；Mac：Cmd + Shift + R）
  • 確認修改的檔案有先儲存
  • 確認你修改的檔案，就是 HTML 實際引入的那一個檔案

Q: 學完這 9 天就能找相關的工作嗎？

A: 這是入門課程，適合想「自己動手把設計稿做成網頁」的設計師或初學者。

  • 如果要成為「網頁設計師」，這份課程足夠讓你理解大部分的版面與樣式寫法，若要獨立完成專案，還需要多加練習與實作。
  • 如果要成為「前端工程師」，還需要學習 JavaScript、版本控制（Git）、框架（React、Vue）、CSS 預處理器與工具（Sass、Tailwind CSS）等進階內容。

Q: 可以跳過某些天的內容嗎？

A: 不建議。課程設計是循序漸進的，每一天都是後續內容的基礎。 不過，如果真的想要更快速上手，可以優先閱讀：

優先順序 內容
必讀 Day 1（選擇器）、Day 4（盒子模型）、Day 6（Flexbox）
建議 Day 2（文字）、Day 5（Display 與 Position）、Day 8（響應式）
可稍後 Day 3（色彩）、Day 7（Grid）、Day 9（動畫）

經驗分享： 面對看不懂的東西，建議一開始先硬著頭皮看完。一開始不懂很正常，多看幾次，或之後遇到相似的情況，慢慢就會懂了。

Q: 學起來很痛苦怎麼辦？

A: 對初學者而言，一開始不適應是很正常的。這份計畫的學習曲線大概是這樣：

  • 第 1-3 天：認識語法與選擇器、文字與色彩，內容直觀，容易看到成果
  • 第 4-5 天：盒子模型與定位的觀念比較抽象，可能會有點挫折，這很正常
  • 第 6-7 天：Flexbox 與 Grid 是最大的關卡，多動手調整參數，觀察變化
  • 第 8-9 天：可以獨立完成一個動態的響應式網頁，恭喜你！

Q: 為什麼同樣的 CSS，在不同瀏覽器看起來不一樣？

A: A: 不同瀏覽器對部分屬性的預設樣式與支援程度略有差異。建議：

  • 使用 Chrome、Firefox、Safari 等主流瀏覽器測試
  • 不確定某個屬性是否被支援時，可查詢 Can I Use 網站，上面有針對各個標籤非常完整的說明
  • 在專案開頭使用 * { margin: 0; padding: 0; box-sizing: border-box; } 減少預設樣式的差異

Q: 需要背下所有 CSS 屬性嗎？

A: 不需要。CSS 屬性非常多，沒有人能全部記住。常用的屬性寫多了自然會記得，不常用的隨時上網查就好。理解「概念」比記住「語法」更重要。

Q: Flexbox 和 Grid 應該用哪一個？

A: 兩者不是二選一，可以搭配使用：

參考情境 建議使用
一行或一列的排列（導覽列、按鈕群組） Flexbox
同時控制行與列（整頁版面、卡片網格） Grid
整體版面 + 元件內部排列 Grid 處理整體，Flexbox 處理內部

Q: 需要使用 CSS 框架（Bootstrap、Tailwind）嗎？

A: 建議先學好原生 CSS。框架是建立在 CSS 之上的工具，如果不了解底層原理，使用框架遇到問題時會很難除錯。熟悉 CSS 之後再學框架，會事半功倍。

Q: 課程還有哪些沒有介紹到的部分呢？

A: 為了維持快速入門的原則，這份課程跳過了許多進階主題，包括：

  • 進階選擇器（屬性選擇器、結構偽類、偽元素）
  • CSS Variables（自訂屬性）
  • 進階 Animation
  • 進階色彩（色彩對比、OKLCH 等色彩空間）
  • Container Queries 與現代 CSS 新功能
  • CSS 預處理器（Sass）與 CSS 框架

Q: CSS 的語法會一直更新嗎？我要怎麼跟上新技術？

A: 會的。CSS 是持續演進的標準，每年都有新的語法與功能加入。不過，新語法不一定所有瀏覽器都已支援。使用前可以先確認支援度（例如 Can I Use 或 MDN 文件上的瀏覽器相容性表格）。
想持續精進 CSS，可以關注以下兩個指標：

1. Interop（跨瀏覽器互通性計畫）

由 Apple、Google、Microsoft、Mozilla 等瀏覽器廠商與相關組織共同參與，從 2022 年開始每年會公布一份「重點項目」清單，集中修正各瀏覽器之間的差異與支援落差。

  • 清單中的項目，代表接下來一年各瀏覽器都會優先處理
  • 適合用來判斷「今年值得學習什麼」
  • 可以在 web-platform-tests 的 Interop 頁面 查看各年度的項目與各瀏覽器目前的通過率

2. Baseline（網路平台實際使用基準）

用來標示某個網頁功能，是否已被主流瀏覽器（Chrome、Edge、Firefox、Safari）普遍支援。

圖示 狀態 說明 使用建議
Widely available
廣泛可用		 已穩定支援一段時間（約 30 個月） 通常可以放心用在一般專案
Newly available
新近可用		 剛被所有主流瀏覽器支援 可以開始嘗試，若要用在正式專案，建議先確認目標使用者的瀏覽器版本
Limited availability
有限支援		 尚未被所有主流瀏覽器支援 學習了解即可，使用時需準備替代方案

Q: 有沒有推薦的學習資源？

A: 推薦學習資源與網站：

  • 🌐 MDN Web Docs
    最權威的 CSS 文件，中文版涵蓋大部分基礎內容
  • 🌐 Web.dev 網站
    由 Google 的 Chrome 瀏覽器開發團隊所維護的完整網頁技術介紹網站
  • 🌐 CSS-Tricks
    豐富的 CSS 技巧與完整指南，Flexbox 與 Grid 指南特別推薦（英文）
  • 🌐 W3Schools CSS Tutorial
    專業完整的網頁開發技術介紹（英文）
  • 🌐 Flexbox Froggy / Grid Garden
    遊戲化學習 Flexbox 與 Grid，有中文介面
  • 🌐 Can I Use
    查詢 CSS 屬性的瀏覽器支援度
