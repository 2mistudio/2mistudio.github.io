Day 9: 漸變與基礎動畫效果

CSS Transition and Basic Animation

一、學習目標

完成本日課程後，你將能夠：

  • 使用 transition 為狀態變化加上過渡效果
  • 理解 timing function（速度曲線）的差異
  • 使用 transform 做位移、縮放、旋轉
  • 使用 @keyframes 與 animation 建立簡單動畫
  • 了解哪些屬性適合做動畫

二、Transition 漸變效果

預設情況下，樣式改變（例如 :hover）是瞬間完成的。transition 讓變化在一段時間內平滑過渡轉換。

運作方式：只要元素的某個屬性值改變（hover、focus、class 切換等），transition 就會在「起始值」與「結束值」之間補上中間的變化。

Transition 的屬性

屬性 說明 範例
transition-property 要過渡的屬性 background-color、all
transition-duration 持續時間 0.3s、300ms
transition-timing-function 速度曲線 ease、linear
transition-delay 延遲開始時間 0s、0.2s

簡寫語法：

以上四種屬性可以分開寫，也可以合併在一起寫。


transition: property duration timing-function delay;

同時過渡多個屬性（用逗號分隔）：

同時要設定多個漸變屬性時，例如「背景」跟「形狀」的改變，可用逗號分隔不同的設定。


transition: background-color 0.3s ease, transform 0.3s ease;

速度曲線 (Timing Function)

值 說明
ease 慢 → 快 → 慢（預設）
linear 等速
ease-in 慢速開始
ease-out 慢速結束
ease-in-out 慢速開始與結束

一般 UI 互動建議： 時間 0.2s ~ 0.4s，搭配 ease 或 ease-out，看起來最自然。

Transition 要寫在哪裡？

⚠️ 重要：寫在元素的原始狀態上，而非轉場後的結果狀態。這樣滑入與滑出都會有漸變轉場效果。


/*元素的原始狀態*/
a {
    background-color: light-grey;
    transition: background-color 0.3s ease;
}
/*轉場後的結果狀態*/
a:hover {
    background-color: red;
}

Transition 的特性：

  • 效能較差（運用 CPU 處理器運算），會跟其他軟體搶效能
  • 建議用在小面積，需要轉場面積過大會嚴重拖累瀏覽器的執行效率，導致畫面延遲或卡頓

三、Transform 變形

transform 可以在不影響版面配置的情況下，改變元素的外觀位置。常與 transition 搭配使用。

函式 說明 範例
translate() 位移 translate(20px, 10px)
scale() 縮放 scale(1.2)
rotate() 旋轉 rotate(45deg)
skew() 傾斜 skew(10deg)

多個變形組合： 用「空格」分開，由左至右依序套用。


transform: translateY(-5px) scale(1.05);

transform-origin： 設定變形的基準點（預設為元素中心）。


transform-origin: center;
transform-origin: top left;

Transform 的特性：

  • 不會改變其他元素的位置（不佔用也不推擠空間）
  • 效能較佳（運用 GPU 顯卡運算），適合做動畫效果
  • inline 元素無法使用 transform

四、Animation 動畫

transition 只能處理「A 狀態到 B 狀態」，需要 自動播放、重複或多個階段時，使用 @keyframes 搭配 animation。

步驟 1：用 @keyframes 定義動畫


@keyframes 動畫名稱 {
  from { 起始樣式 }
  to   { 結束樣式 }
}

/*舉個例子*/
@keyframes show-item {
  from { opacity: 0; }
  to   { opacity: 100%; }
}

多階段使用百分比：


@keyframes 動畫名稱 {
  0%   { 樣式 }
  50%  { 樣式 }
  100% { 樣式 }
}

/*舉個例子*/
@keyframes bounce {
  0%   { transform: translateY(0); }
  50%  { transform: translateY(50px); }
  100% { transform: translateY(0); }
}

步驟 2：用 animation 套用到元素

Animation 的屬性介紹：

屬性 說明 常用值
animation-name 動畫名稱 對應 @keyframes 名稱
animation-duration 持續時間 1s、500ms
animation-timing-function 速度曲線 ease、linear
animation-delay 延遲 0s、1s
animation-iteration-count 重複次數 1、3、infinite
animation-direction 播放方向 normal、reverse、alternate
animation-fill-mode 動畫前後的樣式 none、forwards

簡寫語法：


animation: 名稱 持續時間 速度曲線 延遲 重複次數 方向 填充模式;
animation: name duraion timing-function depay iteration-count direction fill-mode;

animation-fill-mode 說明：

  • none：動畫結束後回到原本樣式（預設）
  • forwards：動畫結束後停在最後一個影格的樣式

五、哪些屬性適合做動畫？

效能佳（建議優先使用）：

  • transform
  • opacity

可以使用，但必須考量對網站執行效能的影響：

  • width、height、margin、padding、top、left 等會改變版面配置的屬性
  • 如果評估非用不可，可從減少變動的面積的大小開始著手，以降低動畫效果對效能的影響程度

六、程式碼範例

按鈕 Hover 效果


.button {
  padding: 10px 20px;
  background-color: #3498db;
  color: white;
  border-radius: 5px;
  transition: background-color 0.3s ease;
}

.button:hover {
  background-color: #2980b9;
}

卡片懸浮效果


.card {
  transition: transform 0.3s ease, box-shadow 0.3s ease;
}

.card:hover {
  transform: translateY(-8px);
  box-shadow: 0 10px 20px rgba(0, 0, 0, 0.15);
}

圖片放大


.image-wrapper {
  overflow: hidden;  /* 隱藏放大後超出的部分 */
}

.image-wrapper img {
  transition: transform 0.4s ease;
}

.image-wrapper:hover img {
  transform: scale(1.1);
}

淡入效果


@keyframes fadeIn {
  from { opacity: 0; }
  to   { opacity: 1; }
}

.fade-in {
  animation: fadeIn 1s ease forwards;
}

由下往上淡入


@keyframes fadeInUp {
  from {
    opacity: 0;
    transform: translateY(20px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

.fade-in-up {
  animation: fadeInUp 0.6s ease-out forwards;
}

無限循環動畫


/* 旋轉的載入圖示 */
@keyframes spin {
  from { transform: rotate(0deg); }
  to   { transform: rotate(360deg); }
}

.loader {
  width: 40px;
  height: 40px;
  border: 4px solid #ddd;
  border-top-color: #3498db;
  border-radius: 50%;
  animation: spin 1s linear infinite;
}

/* 跳動效果 */
@keyframes bounce {
  0%, 100% { transform: translateY(0); }
  50%      { transform: translateY(-20px); }
}

.bounce {
  animation: bounce 1s ease infinite;
}

尊重使用者的動態偏好


@media (prefers-reduced-motion: reduce) {
  * {
    animation: none !important;
    transition: none !important;
  }
}

七、常見錯誤與注意事項

錯誤 1: 忘記設定 duration


/* ❌ 沒有時間，預設為 0s，看不到過渡 */
.button {
  transition: background-color;
}

正確做法：


/* ✅ 一定要指定 duration */
.button {
  transition: background-color 0.3s;
}

錯誤 2: transition 寫在 :hover 裡

錯誤示範：


/* ❌ 滑入有過渡，滑出時瞬間跳回 */
.box {
  background-color: blue;
}

.box:hover {
  background-color: red;
  transition: background-color 0.3s;
}

正確做法：


/* ✅ 寫在原始狀態，進出都有過渡 */
.box {
  background-color: blue;
  transition: background-color 0.3s;
}

.box:hover {
  background-color: red;
}

錯誤 3: 對 display 做過渡

錯誤示範：


/* ❌ display 無法過渡 */
.menu {
  display: none;
  transition: display 0.3s;
}

.menu.open {
  display: block;
}

替代做法：改用 opacity 與 visibility 控制顯示。


.menu {
  opacity: 0;
  visibility: hidden;
  transition: opacity 0.3s, visibility 0.3s;
}

.menu.open {
  opacity: 1;
  visibility: visible;
}

錯誤 4: 動畫名稱不一致

錯誤示範：


/* ❌ animation 名稱與 @keyframes 名稱不同 */
@keyframes fadeIn { /* ... */ }

.box {
  animation: fade-in 1s;
}

正確做法： 兩邊名稱必須完全一致（區分大小寫）。

錯誤 5: 對 inline 元素使用 transform

錯誤示範：


/* ❌ span 預設為 inline，transform 無效 */
span {
  transform: rotate(10deg);
}

正確做法：


/* ✅ 改為 inline-block 或 block */
span {
  display: inline-block;
  transform: rotate(10deg);
}

錯誤 6: 多個 transform 分開寫

錯誤示範：


/* ❌ 後面的 transform 會覆蓋前面的 */
.box {
  transform: translateX(20px);
  transform: rotate(45deg);  /* 只有這行生效 */
}

正確做法：


/* ✅ 寫在同一行 */
.box {
  transform: translateX(20px) rotate(45deg);
}

八、注意事項

1. 動畫不要過度使用

  • 動畫應該輔助使用者理解，而非炫技
  • 過多動畫會分散注意力，也可能影響效能

2. 時間長度的拿捏

  • 小型互動（按鈕、hover）：0.2s ~ 0.3s
  • 較大的變化（面板、彈窗）：0.3s ~ 0.5s
  • 超過 1s 的動畫會讓使用者感到等待

3. 手機沒有 hover

  • 觸控裝置沒有真正的 hover 狀態
  • 重要的資訊或功能不要只依賴 hover 呈現

4. 無障礙考量

  • 部分使用者會在系統中開啟「減少動態效果」
  • 可用 prefers-reduced-motion 尊重此設定

5. 用開發者工具除錯

  • Chrome 開發者工具的 Animations 面板可以檢視、放慢動畫
