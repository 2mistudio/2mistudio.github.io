Day 6: Flexbox 彈性佈局排版

CSS Flexbox Layout

一、學習目標

完成本日課程後，你將能夠：

  • 理解 Flexbox 的基本概念與運作原理
  • 掌握 Flex Container 與 Flex Items 的屬性
  • 使用 justify-content 和 align-items 控制對齊
  • 理解主軸與交叉軸的概念
  • 使用 flex-wrap 處理換行
  • 建立常見的響應式佈局

二、Flexbox 簡介

Flexbox（彈性盒子佈局）是現代 CSS 佈局的核心技術，專門用於一維佈局（水平或垂直）。

主要優勢：

  • 輕鬆實現垂直置中
  • 彈性分配空間
  • 自動調整元素大小
  • 控制元素排列順序
  • 響應式佈局更簡單

適用場景：

  • 導覽列
  • 卡片排列
  • 表單佈局
  • 工具列
  • 頁尾資訊

基本概念

兩個核心角色：

  • Flex Container（外包容器） - 設定 display: flex 的父元素
  • Flex Items（內容項目） - 容器內的直接子元素

兩個重要軸線：

  • Main Axis（主軸） - 項目排列的方向
  • Cross Axis（交叉軸） - 與主軸垂直的方向

三、Flex Container 屬性

1. display

啟用 Flexbox 佈局。


display: flex;        /* 區塊級 Flex 容器 */
display: inline-flex; /* 行內 Flex 容器 */

2. flex-direction

設定主軸方向（項目排列方向）。


flex-direction: row;            /* 水平，從左到右（預設） */
flex-direction: row-reverse;    /* 水平，從右到左 */
flex-direction: column;         /* 垂直，從上到下 */
flex-direction: column-reverse; /* 垂直，從下到上 */

3. justify-content

控制項目在主軸上的對齊方式。


justify-content: flex-start;    /* 靠主軸起點（預設） */
justify-content: flex-end;      /* 靠主軸終點 */
justify-content: center;        /* 置中 */
justify-content: space-between; /* 兩端對齊，項目間距相等 */
justify-content: space-around;  /* 項目兩側間距相等 */
justify-content: space-evenly;  /* 所有間距相等 */

4. align-items

控制項目在交叉軸上的對齊方式。


align-items: stretch;     /* 拉伸填滿容器（預設） */
align-items: flex-start;  /* 靠交叉軸起點 */
align-items: flex-end;    /* 靠交叉軸終點 */
align-items: center;      /* 垂直置中 */
align-items: baseline;    /* 基線對齊 */

5. flex-wrap

控制項目是否換行。


flex-wrap: nowrap;       /* 不換行（預設），項目會壓縮 */
flex-wrap: wrap;         /* 換行 */
flex-wrap: wrap-reverse; /* 反向換行 */

6. align-content

控制多行項目在交叉軸上的對齊（單行無效）。


align-content: stretch;       /* 拉伸（預設） */
align-content: flex-start;    /* 靠起點 */
align-content: flex-end;      /* 靠終點 */
align-content: center;        /* 置中 */
align-content: space-between; /* 兩端對齊 */
align-content: space-around;  /* 周圍間距 */

7. gap

設定項目之間的間距（現代瀏覽器支援）。


gap: 20px;           /* 水平和垂直間距都是 20px */
gap: 20px 10px;      /* 垂直 20px，水平 10px */
row-gap: 20px;       /* 只設定垂直間距 */
column-gap: 10px;    /* 只設定水平間距 */

注意：gap 是相對比較新的 flex 語法，IE 和舊版瀏覽器都不支援。不過，自 2021 年 4 月起已被列為網路平台實際使用基準 Baseline，意思是在這個時間之後推出的新瀏覽器都支援 gap 語法。

四、Flex Items 屬性

1. flex-grow

控制項目的放大比例（分配剩餘空間）。


flex-grow: 0;  /* 不放大（預設） */
flex-grow: 1;  /* 平均分配剩餘空間 */
flex-grow: 2;  /* 獲得兩倍的剩餘空間 */

2. flex-shrink

控制項目的縮小比例（空間不足時）。


flex-shrink: 1;  /* 允許縮小（預設） */
flex-shrink: 0;  /* 不縮小 */
flex-shrink: 2;  /* 縮小兩倍 */

3. flex-basis

設定項目的基準大小（分配空間前的初始大小）。


flex-basis: auto;   /* 根據內容決定（預設） */
flex-basis: 200px;  /* 固定 200px */
flex-basis: 50%;    /* 容器的 50% */

4. flex 簡寫

結合 flex-grow、flex-shrink、flex-basis。


flex: 1;              /* flex-grow: 1, flex-shrink: 1, flex-basis: 0% */
flex: 0 0 200px;      /* 固定 200px，不放大不縮小 */
flex: 1 1 auto;       /* 彈性調整（預設值） */

常用簡寫：


flex: 1;        /* 平均分配空間 */
flex: none;     /* 等於 0 0 auto，不彈性 */
flex: auto;     /* 等於 1 1 auto，完全彈性 */

5. align-self

單獨控制某個項目在交叉軸上的對齊（覆蓋 align-items）。


align-self: auto;       /* 繼承容器的 align-items（預設） */
align-self: flex-start; /* 靠起點 */
align-self: flex-end;   /* 靠終點 */
align-self: center;     /* 置中 */
align-self: stretch;    /* 拉伸 */

6. order

改變項目的排列順序。


order: 0;   /* 預設值 */
order: -1;  /* 排在前面 */
order: 1;   /* 排在後面 */

數值越小越靠前，相同數值按 HTML 順序。

六、常見錯誤與注意事項

錯誤 1: 忘記設定 display: flex

錯誤示範：


/* ❌ 沒有設定 display: flex */
.container {
  justify-content: center;  /* 無效 */
  align-items: center;      /* 無效 */
}

正確做法：


/* ✅ 先設定 display: flex */
.container {
  display: flex;
  justify-content: center;
  align-items: center;
}

錯誤 2: 混淆主軸和交叉軸

錯誤示範：


/* ❌ 想要垂直置中，卻用錯屬性 */
.container {
  display: flex;
  justify-content: center;  /* 這是水平置中 */
}

正確做法：


/* ✅ 垂直置中要用 align-items */
.container {
  display: flex;
  align-items: center;  /* 垂直置中 */
  height: 400px;        /* 容器要有高度 */
}

錯誤 3: align-items 沒效果

錯誤示範：


/* ❌ 容器沒有高度，看不出效果 */
.container {
  display: flex;
  align-items: center;
  /* 沒有設定高度 */
}

正確做法：


/* ✅ 容器要有明確高度 */
.container {
  display: flex;
  align-items: center;
  height: 300px;  /* 或 min-height */
}

錯誤 4: flex 簡寫理解錯誤

錯誤示範：


/* ❌ 誤以為 flex: 1 只設定 flex-grow */
.item {
  flex: 1;
  /* 實際是 flex: 1 1 0%，會將 basis 設為 0 */
}

正確做法：


/* ✅ 理解 flex 簡寫的完整含義 */
.item {
  flex: 1;  /* 等於 flex: 1 1 0% */
}

/* 如果要保留原本大小 */
.item {
  flex: 1 1 auto;  /* 或 flex: auto */
}

七、重點整理

1. Flexbox 是一維佈局

  • 適合處理一行或一列的排列
  • 複雜的二維網格建議使用 Grid

2. justify-content vs align-items

  • justify-content - 主軸對齊
  • align-items - 交叉軸對齊
  • 記住：主軸方向由 flex-direction 決定

3. flex: 1 的含義

  • 等於 flex: 1 1 0%
  • flex item 項目會自動平均分配空間
  • 最常用的彈性設定

4. flex-wrap 的使用

  • 預設 nowrap，內容項目會壓縮
  • 設定 wrap 可以換行（達到響應式效果）
  • 換行後可用 align-content 控制多行對齊

5. 容器高度的重要性

  • align-items 需要容器有高度才看得出效果
  • 可用 height、min-height 或 100vh

6. 瀏覽器支援

  • 現代瀏覽器全面支援 CSS Flexbox 語法（全球瀏覽器支援超過97%）
  • IE 10-11 部分支援（支援性有 bug，但目前 IE 已幾乎完全退役）
  • 雖然 gap 屬性較新，但目前已成為 實際使用基準 Baseline
